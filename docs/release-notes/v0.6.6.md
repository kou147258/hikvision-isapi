# v0.6.6 — fix stale manifest.json version (HA showed 0.6.0 forever)

**User-reported regression**: after every HACS update from v0.6.1
through v0.6.5, Home Assistant continued to display the integration
as **version 0.6.0**. The actual code had shipped five updates with
real bug fixes (config-flow NameError, NVR snapshot URL, device
grouping, digest-auth retry, duplicate sensor unique IDs), but
HA's "About this integration" panel never moved past 0.6.0.

## Root cause

`custom_components/hikvision_isapi_performance/manifest.json`'s
`version` field was set to `0.6.0` at the v0.6.0 rename commit and
was **never bumped** for v0.6.1 → v0.6.5. HACS and HA Core both read
`manifest.json.version` (not the git tag) for the user-facing
"version" string. So all five post-rename releases shipped under the
same 0.6.0 banner in the UI, even though their git tags and release
notes correctly said 0.6.1 / 0.6.2 / 0.6.3 / 0.6.4 / 0.6.5.

Every release workflow created a tag and a GitHub release but did
not touch `manifest.json`. This is the integration-version pinning
contract HA uses to know which build is installed — failing to bump
it makes the version displayed in HA meaningless.

## Fix

- `manifest.json` version bumped from `0.6.0` → **`0.6.6`**. This
  catches up to all five post-rename releases' actual code state
  and gives HA a real number to display.
- After HACS pulls this release, HA's "About this integration"
  panel will show **0.6.6** for the first time (and stay correct
  going forward as long as we bump manifest.json with each release).

## What did NOT change

- No code changes. All v0.6.1 → v0.6.5 bug fixes are still in place.
- No test changes (59/59 still pass).
- The integration's `domain`, `name`, and folder remain unchanged.

## Process lesson (recorded in agent memory)

**Every release that changes behavior MUST also bump
`manifest.json.version`.** The git tag and release notes are for
humans; `manifest.json.version` is what HA actually reads. A
release without a manifest bump is invisible to HA's UI.

## Upgrade path

HACS → 已安装的集成 → Hikvision ISAPI Performance → 更新到 v0.6.6 →
重启 Home Assistant. HA's "About this integration" panel will now
show **0.6.6** instead of 0.6.0.

Users who want to verify the new manifest is loaded can check
`<config>/custom_components/hikvision_isapi_performance/manifest.json`
— the `version` field should be `0.6.6` after HACS finishes
updating.
